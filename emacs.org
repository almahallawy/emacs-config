* Generate the emacs configuration file
Nothing to do by hand.  The repo's .emacs (hand-written, not tangled; see
whenever their .el output is missing or older, then loads kia-config and
compiles my-gptel*.el.  C-c C-v t still works for applying a change without
restarting.

~/.emacs contains only (keep Custom's block below it):

(load "~/src/emacs-config/.emacs")

* Prerequisites
Clone these into ~/src before the first start; they are loaded from there:
- https://github.com/karthink/gptel.git          -> ~/src/gptel
- https://github.com/karthink/gptel-agent.git    -> ~/src/gptel-agent
- https://github.com/jeremy-compostella/cscope   -> ~/src/cscope

System packages:
- pandoc (markdown-mode preview/export): sudo apt install pandoc
- pdf-tools build deps (epdfinfo is compiled on first load, see PDF):
  sudo apt install libpoppler-glib-dev libpoppler-private-dev libpng-dev
  zlib1g-dev autoconf automake gcc make pkg-config

Shell (manual step):
- ln -s ~/src/emacs-config/emacs_bash ~/.emacs_bash
  (see Shell > ~/.emacs_bash).  Without it M-x shell and M-x ssh have no
  prompt colours, no directory tracking (default-directory and F1 buffer
  names don't follow cd), no colour from git/ls/grep, and pagers (less)
  break.  Nothing is needed in ~/.bashrc, locally or on remote hosts.

(defun c-lineup-arglist-tabs-only (ignored)
  "Line up argument lists by tabs, not spaces"
  (let* ((anchor (c-langelem-pos c-syntactic-element))
	 (column (c-langelem-2nd-pos c-syntactic-element))
	 (offset (- (1+ column) anchor))
	 (steps (floor offset c-basic-offset)))
    (* (max steps 1)
       c-basic-offset)))

(defun my-gptel-compile-after-tangle ()
  "Byte-compile my-gptel*.el right after it is tangled.
Runs in the tangled file's buffer (`org-babel-post-tangle-hook')."
  (when (and buffer-file-name
             (string-match-p "\\`my-gptel.*\\.el\\'"
                             (file-name-nondirectory buffer-file-name)))
    (byte-compile-file buffer-file-name)))

** Directory tracking (OSC 7)
The shell reports its cwd after every prompt, so `default-directory'
(C-x C-f, dired, compile) follows `cd'.  Needs ~/.emacs_bash (below).
- Mickey: running-shells-in-emacs-overview, "Directory Tracking" section
  ("I strongly recommend you go to the trouble of getting it to work";
   disable shell-dirtrack-mode so it doesn't interfere)
- Prot: prot-emacs-essentials.el, comint section

*** ~/.emacs_bash
Jeremy's approach (~/src/j2m-emacs-config: ~/.emacs_bash is a symlink into
his config repo).  M-x shell sends ~/.emacs_bash to every new bash as its
first input (shell.el, `shell': startfile "~/.emacs_" + shell name), also
for shells started on a remote host via TRAMP.  So this setup lives only on
the laptop: ~/.bashrc (local or remote) needs nothing for Emacs, and
terminals (Ptyxis) are unaffected.

Setup once per laptop (tangled file is committed, so a fresh clone works):
#+begin_src sh :tangle no
ln -s ~/src/emacs-config/emacs_bash ~/.emacs_bash
#+end_src

The lines are typed into bash, not sourced, so:
- No comments in the file: each line would print an extra prompt.
  Notes are here instead.
- Each line still prints a prompt while it's read; the Elisp below deletes
  them once the last line has run (it sets PROMPT_COMMAND, so the first
  OSC 7 marks the end; its `echo' puts the real prompt on a fresh line).
- `set +o history' / `set -o history': keep these lines out of bash history
  (first line starts with a space for HISTCONTROL=ignorespace; `-i' keeps
  that space when tangling).
- Runs after ~/.bashrc, so it overrides its PS1/PROMPT_COMMAND.
- PROMPT_COMMAND is only extended once (safe if run twice).

What each line does:
1. OSC 7 function (Mickey's `myprompt'): report host and cwd.
2. Pager off (Prot's .bashrc, quoted in prot-emacs-essentials.el "Standard
   Unix Shell"); TERM=dumb-emacs-ansi (ncurses terminfo: 8 colors, no cursor
   movement) lets git/ls/grep emit colour; COLORTERM=1 is Prot's
   conservative colour hint.
3. Ours: uutils ls (Ubuntu default) refuses colour when TERM=dumb*, even
   with --color=always; GNU ls (gnuls) doesn't.
4. Ours: tmux refuses dumb-emacs-ansi (terminfo has hc, "hardcopy"); plain
   dumb works for ls/new -d/kill-session.  Attach needs a real terminal.
5. Ours: Debian's PS1 is coloured only for xterm/256color; force it.
6. Ours: HISTFILE: TRAMP starts remote shells with HISTFILE=~/.tramp_history
   (`tramp-histfile-override', to keep its own commands out of history), so
   commands typed in M-x ssh were never saved.  No-op locally.
7. Run the OSC 7 function before every prompt (Mickey).  Ours: `history -a'
   appends each command to HISTFILE as it runs, so it's saved even if the
   buffer is killed (bash didn't write it then) or the connection drops,
   and new shells see commands from open ones.  History back on.
#+begin_src sh -i :tangle emacs_bash
 set +o history
__emacs_osc7() { history -a; printf "\e]7;file://%s%s\e\\" "$HOSTNAME" "$PWD"; }
HISTFILE=~/.bash_history
export PAGER=cat GIT_PAGER=cat TERM=dumb-emacs-ansi COLORTERM=1
command -v gnuls >/dev/null && alias ls='gnuls --color=auto'
tmux() { TERM=dumb command tmux "$@"; }
PS1='${debian_chroot:+($debian_chroot)}\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
case ";$PROMPT_COMMAND;" in *";__emacs_osc7;"*) ;; *) PROMPT_COMMAND="__emacs_osc7${PROMPT_COMMAND:+;$PROMPT_COMMAND}" ;; esac; set -o history; echo
#+end_src

#+BEGIN_SRC emacs-lisp
(defun my-shell--drop-startup-prompts (output)
  "Delete the prompts bash printed while ~/.emacs_bash was typed in.
The first OSC 7 comes after its last line; everything before the current
line is startup noise."
  (when (string-search "\e]7;" output)
    (remove-hook 'comint-output-filter-functions
                 #'my-shell--drop-startup-prompts t)
    (let ((inhibit-read-only t)
          (end (save-excursion
                 (goto-char (process-mark (get-buffer-process (current-buffer))))
                 (line-beginning-position))))
      (delete-region (point-min) end))))

(defun my-shell--startup-cleanup ()
  ;; "~" is the local home even in TRAMP shells, like shell.el's startfile.
  (when (file-exists-p "~/.emacs_bash")
    (add-hook 'comint-output-filter-functions
              #'my-shell--drop-startup-prompts t t)))
(add-hook 'shell-mode-hook #'my-shell--startup-cleanup)
#+END_SRC

** Remote shells: M-x ssh (TRAMP)
Jeremy's `ssh' (j2m-tools.el, github.com/jeremy-compostella/j2m-tools):
start the shell through TRAMP, so bash runs on the remote but still gets
~/.emacs_bash from the laptop.  Remote machines need no setup.  The shell,
C-x C-f, dired and TAB share one TRAMP connection.
- M-x ssh (alias for `my-ssh', unless something else defines `ssh'):
  prompts for user@host.  F1 in a remote dired/file buffer works too.
- `explicit-shell-file-name': without it a TRAMP shell runs /bin/sh (the
  connection-local default), and shell.el then looks for ~/.emacs_sh
  instead of ~/.emacs_bash.  Jeremy sets it too.
- `shell-history-file-name': shell-mode asks the remote for $HISTFILE with
  a non-interactive shell, where bash leaves it unset, so remote shells
  started with an empty history.  This gives Up/Down the remote
  ~/.bash_history (Jeremy: same idea); locally it's the same file as
  before.  Writing back is done by bash (HISTFILE + `history -a' in
  ~/.emacs_bash).
- `comint-input-ring-size': Up/Down holds 500 by default; shell-mode copies
  $HISTSIZE only if it's in Emacs's environment, and ~/.bashrc sets it
  inside bash only.  Ours: 1000, same as Ubuntu's HISTSIZE.
- OSC 7: the built-in `ansi-osc-directory-tracker' ignores reports from
  other hosts.  Ours: in a shell started via TRAMP, keep its prefix
  (method/user/hops) and swap in the reported path.  Sets
  `default-directory' only; the TRAMP connection already exists.
- Buffer name: *shell user@host:DIR* from the TRAMP path (host as typed),
  so F1 in a remote buffer finds the existing shell.
- Not covered: `ssh host' typed inside a shell.  The remote doesn't get
  ~/.emacs_bash, so no tracking or colours there.  Use M-x ssh.
- `my-ssh-history' survives restarts only if savehist-mode is on (it's off).

#+BEGIN_SRC emacs-lisp
(setq explicit-shell-file-name "/bin/bash"
      shell-history-file-name "~/.bash_history")
(setq-default comint-input-ring-size 1000)

(defvar-local my-shell--origin nil
  "TRAMP prefix the shell process was started on, or nil if local.")

(defun my-shell--record-origin ()
  (setq my-shell--origin (file-remote-p default-directory)))
(add-hook 'shell-mode-hook #'my-shell--record-origin)

(defun my-ansi-osc-directory-tracker (_ text)
  "Like `ansi-osc-directory-tracker', but follow shells started via TRAMP."
  (let* ((url (url-generic-parse-url text))
         (host (url-host url))
         (path (url-unhex-string (url-filename url))))
    (when (and (equal (url-type url) "file") (file-name-absolute-p path))
      (cond
       (my-shell--origin
        (setq default-directory
              (file-name-as-directory (concat my-shell--origin path))))
       ((or (member host '(nil "")) (string= host (downcase (system-name))))
        (setq default-directory (file-name-as-directory path)))))))

(with-eval-after-load 'ansi-osc
  (setf (alist-get "7" ansi-osc-handlers nil nil #'equal)
        #'my-ansi-osc-directory-tracker))

(defvar my-ssh-history nil "History of `my-ssh' targets.")

(defun my-ssh (target)
  "Shell on TARGET (user@host), started via TRAMP.
Based on Jeremy's `ssh' (j2m-tools.el)."
  (interactive (list (read-string "ssh user@host: " nil 'my-ssh-history)))
  ;; Expanding the remote ~ also opens the connection (password, host key)
  ;; before any buffer is created.
  (let ((default-directory (expand-file-name (concat "/ssh:" target ":~/"))))
    (my-shell)))

(unless (fboundp 'ssh)
  (defalias 'ssh #'my-ssh))
#+END_SRC

** TRAMP
Remote files (C-x C-f /ssh:user@host:path, and the remote shells above).
- Prot: prot-emacs-essentials.el (auto-save/trash off, remote shell bash;
  he uses a 600s connection timeout, we use 10s).  Rest is ours.
- After a disconnect: M-x tramp-cleanup-this-connection, then retry.
- Dead host also logs "Could not retrieve `tramp-own-remote-path'" in
  *Warnings*: harmless, it's the failed connect.

~/.ssh/config (copy, not tangled; create it with mode 600).  General
settings for every host, so new test machines need no entry.  Tested on
a test host: second ssh 0.42s -> 0.04s; unreachable host fails in 10s.
- ServerAlive*: notice a dead link (laptop sleep, network change) in ~90s
  instead of hanging.
- ConnectTimeout: default is the kernel TCP timeout (~2 min); TRAMP
  retries, so one C-x C-f to a dead host froze Emacs ~8 min without it.
- ControlMaster: typed ssh/scp reuse one connection per user@host:port.
  TRAMP has its own (`tramp-use-connection-share', ~/.cache/emacs/tramp.*).
- Stale master after reconnect: ssh -O exit user@host (or rm ~/.ssh/cm-*).
#+begin_src conf :tangle no
Host *
    ServerAliveInterval 30
    ServerAliveCountMax 3
    ConnectTimeout 10
    ControlMaster auto
    ControlPath ~/.ssh/cm-%r@%h:%p
    ControlPersist 10m
#+end_src

#+BEGIN_SRC emacs-lisp
(with-eval-after-load 'tramp

  ;; a laptop on flaky networks shouldn't freeze Emacs

  ;; Ours: TRAMP shows its error buffer 30s after a failed connect and
  ;; retries ~3 times per command, so a dead host froze Emacs ~2 min
  ;; even with ConnectTimeout 10.  Keep the message, shorten the wait.
  (setq tramp-error-show-message-timeout 3)
  ;; Prot: shell for TRAMP's own commands

** Up/Down: history at prompt, movement elsewhere
- Prot: https://github.com/protesilaos/dotfiles/blob/master/emacs/.emacs.d/prot-lisp/prot-shell.el
  (`prot-shell-up-dwim' / `prot-shell-down-dwim')
- Ours: uses the "matching" history commands, so typing a prefix
  (e.g. git) then Up only cycles commands starting with it (like bash).

#+BEGIN_SRC emacs-lisp
(defun my-shell-up (arg)
  "History at prompt, else move up.  Based on Prot's `prot-shell-up-dwim'."
  (interactive "^p")
  (if (comint-after-pmark-p)
      (progn
        ;; Ours: comint checks `last-command' to continue a search.
        (setq this-command 'comint-previous-matching-input-from-input)
        (comint-previous-matching-input-from-input arg))
    (forward-line (- arg))))

(defun my-shell-down (arg)
  "History at prompt, else move down.  Based on Prot's `prot-shell-down-dwim'."
  (interactive "^p")
  (if (comint-after-pmark-p)
      (progn
        (setq this-command 'comint-next-matching-input-from-input)
        (comint-next-matching-input-from-input arg))
    (forward-line arg)))

(with-eval-after-load 'shell
  (define-key shell-mode-map (kbd "<up>")   #'my-shell-up)
  (define-key shell-mode-map (kbd "<down>") #'my-shell-down)
  ;; Prot: easier key for clearing the buffer (default C-c M-o)
  (define-key shell-mode-map (kbd "C-c C-k") #'comint-clear-buffer))
#+END_SRC

** F1: one shell per directory
- Prot: prot-shell.el (`prot-shell', bound to F1): new shell named after
  `default-directory', reused if one exists; renamed after `cd'.
- Ours: rename on any directory change reported by OSC 7 (pushd, scripts,
  aliases), not only typed `cd ...'; applies to every shell-mode buffer.
- C-c s is taken by cscope, so F1 only (help stays on C-h).

#+BEGIN_SRC emacs-lisp
(defun my-shell--name (dir)
  (let ((d (abbreviate-file-name (directory-file-name dir))))
    ;; Ours: remote: *shell user@host:DIR* instead of the full TRAMP path
    (if (file-remote-p d)
        (let ((user (file-remote-p d 'user)))
          (format "*shell %s%s:%s*" (if user (concat user "@") "")
                  (file-remote-p d 'host) (file-remote-p d 'localname)))
      (format "*shell %s*" d))))

(defun my-shell--rename-on-cd (_output)
  "Rename the shell buffer when `default-directory' changes."
  (let ((name (my-shell--name default-directory)))
    (unless (string-prefix-p name (buffer-name))
      (rename-buffer name t))))

(defun my-shell--track-name ()
  ;; APPEND so it runs after `comint-osc-process-output' updates the dir.
  (add-hook 'comint-output-filter-functions #'my-shell--rename-on-cd t t))

;; Ours: every shell (M-x shell too) is named after its cwd, like a
;; terminal title.  Note: M-x shell then starts a new shell each time.
(add-hook 'shell-mode-hook #'my-shell--track-name)

(defun my-shell ()
  "Shell for `default-directory', named after it; reuse if it exists.
Based on Prot's `prot-shell'.  In a remote directory the shell runs there
via TRAMP (see `my-ssh')."
  (interactive)
  (shell (my-shell--name default-directory)))

(global-set-key (kbd "<f1>") #'my-shell)
#+END_SRC
